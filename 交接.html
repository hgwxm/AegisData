📦 AegisData 智能财务审计平台 - 项目交接文档

项目名称： AegisData 智能财务审计平台

适用场景： 华为 ICT 大赛国赛 Demo 演示

技术栈： Vue 3 (CDN) + 纯原生 CSS + ECharts (数据大屏) + JSZip (图表导出)

运行方式： 纯前端双击运行，无需 Node.js 构建。支持本地直接打开或部署至 Vercel/Netlify。

一、 交接文件清单

请确保项目文件夹的层级结构如下，不要遗漏文件或文件夹：

AegisData/
├── index.html          # 主页面（包含所有界面结构、CDN 引入、防闪烁配置）
├── css/
│   └── style.css       # 全站样式（包含三态主题、响应式、组件美化）
└── js/
    ├── config.js       # 全局配置（USE_MOCK, baseURL）
    ├── api.js          # 接口封装（目前仅 Mock 了 login）
    └── app.js          # Vue3 核心逻辑（所有业务流、大屏渲染、导出、交互）

二、 核心功能与交互逻辑（答辩/演示重点）

  1. 行业动态联动：进入系统后选择行业（15 个卡片）。后续所有的假数据、图表、凭证内容都会根据行业动态生成（制造业、医疗业、教育业的数据完全不同，极具说服力）。
  2. AI 分析计时与步骤：在上传数据后，AI 分析界面会展示 5 个详细的解析步骤，并附带实时计时器，展示 AI 的工作效率（符合真实业务场景）。
  3. 一键导出大屏：在“结果产出”点击进入数据大屏，底部有一个“一键导出图表压缩包”按钮，利用浏览器端 JSZip 和 FileSaver 实时打包 3 张高清图表（PNG格式）并下载为 ZIP。
  4. 全局主题切换：在个人设置中，支持“浅色 / 深色 / 护眼”三种模式无缝切换。
  5. 双头像菜单：右上角（全局设置）和左下角（个人状态）均设有头像，点击均可弹出独立菜单，互不干扰。

三、 后端联调指南（给后端同学）

目前系统默认走的是 USE_MOCK: true 的前端假数据。如需联调后端，请按以下步骤操作：

1. 修改配置文件

打开 js/config.js，修改如下：

const CONFIG = {
  USE_MOCK: false, 
  baseURL: 'http://你的后端地址:端口' 
};

2. 对接接口契约

请在 js/api.js 中新增或修改对应的 fetch 请求。以下是前后端约定的核心接口：

接口路径 请求方式 入参 返回数据要求
/api/login POST { username, password, industry } { code: 200, token: "xxx", data: {...} }
/api/upload POST FormData (file + industry) { code: 200, data: { reportId, anomalyCount } }
/api/anomalies GET ?reportId=xxx { code: 200, data: [{ anomalyId, date, subject, amount, direction, anomalyType, riskLevel, description }] }
/api/explain POST { anomalyId } { code: 200, data: { explanation: "文字说明" } }
/api/chat POST { message, reportId } { code: 200, data: { reply: "文字说明" } }
注意：后端同学在开发时，异常类型字段名必须为 anomalyType，风险等级必须为 riskLevel，前端严重依赖这两个字段渲染不同颜色的风险标签。

四、 常见问题排查（排雷指南）

  • 本地双击 index.html 白屏/代码乱码：请检查 css/style.css 和 js/*.js 的路径是否和 index.html 的相对路径一致。确保 index.html 里的 CDN 能够正常访问（需要联网）。
  • 左下角头像菜单不弹出：请确保使用的是最新版的 index.html 和 js/app.js。左下角菜单使用了独立的 showLeftUserMenu 变量和 @click.stop 阻断冒泡。
  • 大屏导出失败：确保 index.html 的 <head> 中正确引入了 jszip.min.js 和 FileSaver.min.js。

五、 部署上线建议

如果需要在公网上进行展示，推荐使用以下两种免费方式：

  • Netlify Drop：打开 app.netlify.com/drop，直接将 AegisData 文件夹拖拽进去，即刻生成公网链接。
  • Vercel：在控制台新建项目，关联 Git 仓库或直接拖拽，提供专属的 .vercel.app 域名。
